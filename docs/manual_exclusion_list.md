# 上声全濁字異例候補の手動除外リスト

作成日: 2026-06-02
根拠ファイル: `diff/diff_*.md`, `diff/deleted_pronunciations.tsv`

この文書は、上声全濁字でありながら観智院本の声点が平声・去声などに見える候補について、個別確認後に手動で `krm_pronunciations.tsv` に反映した補正・除外理由をまとめたものである。`krm.db` は参照対象のみで、直接編集しない。

## 判定区分

| 区分 | 内容 |
|---|---|
| 除外 | 上声全濁字の声調対応を集計する際、通常例として扱わないもの。音注字側の声点、反切下字、俗音、別系統音、汚れなどを含む。 |
| 補正 | 明らかな誤入力・転記ミス・誤写推定を TSV に反映したもの。 |
| 存疑 | 異例の可能性を残すが、音注字・声点位置・多音字などの事情を注記したもの。 |
| 確認のみ | 検討したが、今回の手動補正・除外注記を加えなかったもの。 |
