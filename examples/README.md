# Claude Code を使った KRM データ分析ガイド

このガイドでは、観智院本類聚名義抄データベース（KRM）を
**Claude Code** を使って分析する方法を紹介します。

Pythonのインストールや、スクリプトの知識は不要です。
Claude Code に日本語で質問するだけで、データの集計・照合・検索ができます。

---

## 準備

1. [claude.ai/code](https://claude.ai/code) にアクセス（Proプラン、月20ドルが必要です）
2. このリポジトリをダウンロード（GitHubの「Code」→「Download ZIP」でOKです）
3. ZIPを展開し、Claude Code でそのフォルダを開く

以上で準備完了です。

---

## 基本的な使い方

Claude Code のチャット欄に、以下のような質問を**コピーして貼り付けて**実行してください。
CLAUDE.md がリポジトリに入っているので、データ構造の説明なしで正しく処理されます。

## 質問例集

### 1. データの整合性を確認する

データが正しくつながっているかを確認できます。

```
krm_wakun.tsv にあって krm_main.tsv にない entry_id があるか確認して
```

```
krm_pronunciations.tsv にあって krm_notes.tsv にない definition_seq_id があるか確認して
```

正常なデータベースであれば「差分なし」と返ってきます。

---

### 2. 巻ごとの集計

```
巻ごと（volume_name）に、総エントリ数・和訓あり件数・和訓割合を一覧表で出して
```

**実行結果の例：**

| volume_name | 総エントリ | 和訓あり | 割合 |
|---|---:|---:|---:|
| 仏上 | 2,192 | 1,164 | 53.1% |
| 仏中 | 3,786 | 1,729 | 45.7% |
| … | … | … | … |
| **合計** | **32,607** | **13,995** | **42.9%** |

仏上・僧上で和訓割合が高く、法中・僧下で低い傾向があります。

---

### 3. 部首ごとの集計

```
部首ごと（radical_name）に和訓割合を出して、上位10・下位10を見せて
```

**実行結果の例（上位）：**

| radical_name | 総エントリ | 和訓あり | 割合 |
|---|---:|---:|---:|
| 一 | 135 | 99 | 73.3% |
| 寸 | 41 | 30 | 73.2% |
| 彳 | 185 | 126 | 68.1% |

**実行結果の例（下位）：**

| radical_name | 総エントリ | 和訓あり | 割合 |
|---|---:|---:|---:|
| 豸 | 130 | 15 | 11.5% |
| 麥 | 89 | 12 | 13.5% |
| 邑 | 327 | 54 | 16.5% |

動物・植物・地名系の部首で和訓が少ない傾向があります。

## スクリプトを保存する

同じ集計を繰り返し使いたい場合は、スクリプトとして保存できます。

```
今の集計を examples/scripts/ フォルダに analyze_wakun.py として保存して
```

保存されたスクリプトは次回以降、Claude Code なしでも

```bash
python examples/scripts/analyze_wakun.py
```

で実行できます（Pythonが使える環境の場合）。

## よくある質問

**Q. TSVファイルをExcelで開いたら文字化けしました**

UTF-8で保存されています。Excelで開く場合は「データ」→「テキストファイル」からインポートし、文字コードに「UTF-8」を選んでください。

**Q. JSONファイルとTSVファイル、どちらを使えばいいですか？**

Claude Codeで分析する場合はどちらでも構いません。TSVの方が軽量です。JSONは`krm_notes.json`のように入れ子構造のデータを扱うときに便利です。

**Q. 旧バージョンのファイル（`KRM_`で始まるもの）との違いは？**

2025年3月に仕様変更を行いました。現在は小文字の`krm_`で始まるファイルが最新版です。声点の表記方法などが変更されています。詳細はREADME_jp.mdの「仕様変更」節を参照してください。
